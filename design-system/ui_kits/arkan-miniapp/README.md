# Аркан — Telegram Mini App (UI kit)

Кликабельная рекреация всех ключевых экранов. Открывается `index.html`; поток:
онбординг (3 шага + согласие) → формулировка вопроса → расклад по одной карте →
итог целиком → история → карта дня → профиль (там же переключение тёмной/светлой темы).

| Файл | Экран |
| --- | --- |
| `Shell.jsx` | `Phone` (390×844), `TgHeader`, `Scroll`, `Dock`, `TabBar` |
| `Onboarding.jsx` | Первый вход, объяснение формата, согласие на обработку данных |
| `AskQuestion.jsx` | Формулировка вопроса, подсказки-чипы, состояния поля |
| `Reading.jsx` | Процесс расклада: ожидание → рубашка → раскрытие → толкование → уточнение |
| `Summary.jsx` | Итог расклада целиком + нижний шит «Поделиться» |
| `History.jsx` | История раскладов (и пустое состояние через `empty`) |
| `CardOfDay.jsx` | Карта дня |
| `Profile.jsx` | Профиль, настройки, модалка удаления |
| `data.js` | Тексты расклада и истории |

Экраны собраны из компонентов дизайн-системы (`window.DesignSystem_8c38cb`), кроме шелла,
`Icon` (маска по Lucide) и строк настроек — это специфика кита.

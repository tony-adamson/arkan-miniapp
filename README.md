# Аркан

ИИ-таролог в формате диалога. Расклад раскрывается по одной карте, между картами
система задаёт уточняющий вопрос, и следующая интерпретация учитывает ответ.
Карты здесь — не механизм предсказания, а рамка для разбора собственной ситуации.

## Статус

Этап 1 акселератора Sber500 x Disrupt — разработка MVP.
Старт 15.09.2026, дедлайн 15.10.2026.

## Конструкция продукта

Два слоя, связанные памятью о незакрытой ситуации:

| Слой | Когда | Глубина | Цикл возврата |
| --- | --- | --- | --- |
| **Большой расклад** | отношения, работа, выбор, затянувшаяся неопределённость | 8–12 обращений за сессию | недели и месяцы |
| **Карта дня** | ежедневно | 1–3 обращения | каждый день |

Карта дня вытягивается в контексте незакрытой ситуации из последнего большого
расклада: утром — карта в привязке к открытому вопросу, вечером — сверка, что
проявилось. Подробнее — [docs/product.md](docs/product.md).

## Архитектурный принцип

**Модель предлагает, код решает.**

- Карты выбирает детерминированный криптостойкий генератор с сохраняемым сидом —
  до обращения к модели. Честность расклада воспроизводима.
- Структуры раскладов — конфигурация, а не текст промпта.
- Толкование строится через RAG по экспертной базе и перед показом проверяется
  на соответствие ей отдельным шагом. Модель отвечает только за формулировку.
